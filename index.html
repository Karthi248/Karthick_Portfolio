Bus Scam Shield

NextGen AI Hacks 2026 · 24 hours · Team Leader (team of 4)

A Chrome extension and backend that warn a passenger before they pay on a fake bus-booking site.

Travel site→Extension→Flask backend→Risk verdict→Green / yellow / red banner

The problem

Fake omnibus portals, ticket scalping and fake operator listings in South Chennai. Tools like redBus protect only their own bookings, and Truecaller or the 1930 helpline help after contact or loss. Nothing stopped a passenger before paying.

What I built

Eight checks: domain age, SSL, look-alike domains, contact info, payment gateway, operator registry, GST/PAN and vehicle registration, combined into a weighted risk score. On top: a Random Forest second opinion, Google Safe Browsing, Claude analysis, signed QR tickets, a scalping-risk check and a user reporting channel with an admin-approved ban list.

Jury rounds

Round 1: “it looks like a lookup table”, so we added machine learning and unified all five components. Final round: “anyone can copy an API key from an extension”, so we moved every key and call to the backend. The lesson: anything shipped in an extension is public.

Problems I fixed

A genuine site (redbus.com) was flagged high risk, fixed with a redirect check. Slow similarity checks were replaced with faster text matching. Python and library setup issues cost hours.

Honest limits

The Random Forest was trained on synthetic data, so its accuracy says nothing about the real world. The operator list comes from a tourism registry, not RTO permit data. No detector is perfect, which is why users can report sites.

PlantCare

Smart India Hackathon 2026 · SIH26131 · Team Leader (team of 6)

Crop disease detection that works offline: photograph a leaf, hear the disease and remedy in your own language.

Leaf photo→MobileNetV2 (TFLite)→Confidence check→Remedy database→Regional voice

The problem

Farmers lose 15–30% of yield to diseases found too late. Many rural and elderly farmers cannot use English-only apps, and expert help can mean waiting for an officer’s visit.

What I built

A MobileNetV2 transfer-learning model (frozen base, Dense 128, Dropout, softmax) trained on PlantVillage, 54,000+ images, reaching 93% accuracy across 38 disease classes. Converted to TensorFlow Lite so detection runs on the phone with no internet.

Making it reliable

Some diseases had 36 times fewer images than others, so I used class-weighted loss instead of duplicating images, plus rotate, zoom and flip augmentation. Below 60% confidence the app asks for a clearer photo instead of guessing.

Built for the farmer

Disease names, remedies and prevention tips are spoken in the regional language, and remedies come from a local database, so it works for low-literacy users with a basic phone.

Honest limits

PlantVillage is mostly lab-style photos, so field accuracy is still unproven. Next steps: real Indian field images, crops like rice, cotton and sugarcane, and checking languages and remedies with native speakers and agricultural experts.

Rice Type Classification

Seminar project

Predicting rice type from grain-shape measurements, comparing six machine learning models.

18,185 grains→Scale features→6 models→5-fold CV→SVM: 99.04%

The data

18,185 rice grains, each with 10 shape features such as area, axis lengths, roundness and aspect ratio. Class 0 has 8,200 grains and Class 1 has 9,985.

The method

Explored the data with boxplots, violin plots, a correlation heatmap and PCA, then split 80/20. The scaler was fit on training data only so no test data leaks in. Compared SVM, Random Forest, Logistic Regression, KNN, Decision Tree and Naive Bayes.

The result

SVM was best at 99.04% cross-validated accuracy, and it classified 3,597 of 3,637 test grains correctly. All six models scored above 98%.

What I found

Roundness mattered most by far, and Extent added almost nothing. Area, ConvexArea and EquivDiameter are almost perfectly correlated, so some features are redundant.

Honest limits

The features were already extracted from images, and every model scored above 98%, so this shows the classes are easy to separate, not how it would do on raw images or another dataset.
